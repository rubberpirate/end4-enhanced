The desktop battery widget lives in `modules/ii/background/widgets/battery/`. `background.widgets.battery` stores its enable flag, placement, coordinates, and size; the base config enables it at `(600, 100)`, size 200. It is registered in `WidgetsLoader.qml`, `DesktopWidgets.qml`, and Desktop settings. It uses the existing `Battery` singleton rather than Nebula's services. Test via `python3 tests/battery/check.py` on Wayland. Keep `laucnher/` untracked when committing integration work.
